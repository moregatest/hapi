🧹 Clear Cache & Service Worker

如果您看不到最新的功能（例如上傳按鈕），請使用此頁面清除緩存。

狀態： 準備清除緩存

手動清除步驟：

  1. 在瀏覽器中按 F12 打開開發者工具
  2. 前往 Application (Chrome) 或 Storage (Firefox) 標籤
  3. 點擊 Clear site data 或 Clear storage
  4. 重新加載頁面 (Ctrl+Shift+R 或 Cmd+Shift+R)

手機瀏覽器：

  • iOS Safari: 設定 → Safari → 清除歷史記錄與網站資料
  • Android Chrome: 設定 → 隱私權 → 清除瀏覽資料
